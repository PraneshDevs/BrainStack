# 🧠 BrainStack

"Stacking knowledge, one concept at a time."

BrainStack is my personal learning hub — a structured space to organize study materials, notes, and curated resources across Statistics, Data Science, Machine Learning, and AI.

## 📂 Contents
- Notes → structured explanations of key topics
- Study Materials → cheat sheets, references, and summaries
- Practice Notebooks → Jupyter notebooks for hands‑on exploration
- Resources → links, books, and guides that support deeper learning

This repository grows with my journey — each new idea adds another block to the stack, building a comprehensive library of knowledge.
